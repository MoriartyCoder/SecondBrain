
# What is a partial derivative?

[[https://tutorial.math.lamar.edu/classes/calciii/partialderivatives.aspx|Recall that given a function of one variable, f(x), the derivative, f′(x), represents the rate of change of the function as x changes.]]
While a function can have a single variable, it can also contain more.  We still want to know how much the change of a variable influences the rate of change. By taking the partial derivative w.r.t a variable we can maintain the availability of this information even though this time it might be dependent on other variables.
$$f(x,y) = x^2y^2$$
$$f'(x,y) = 2xy^2$$
$$f'(x,y) = x^22y$$
