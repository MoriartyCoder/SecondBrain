It can be used to perform scans on Windows and Samba Systems!

## Options
* -U: get userlist
* -M: get machine list
* -N: get namelist dump
* -S: get sharelist
* -P: get password policy information
* -G get group and member list
* -a: full basic enumeration (all of the above)
* -h: help

Tipp: Pipe the output into a file to perform the scan just once. The best way to use is tee.
