
# Variable notation

### Non-typical data type notation
| Non-typical | Notation |
| ----------- | -------- |
| unsigned    | u        |

### Data type notation
| Data Type   | Notation |
| ----------- | -------- |
| int         | i        |
| short       | s        |
| long        | l        |
| char/string | c        |
| float       | f        |
| double      | d        |
| boolean     | b        |
| Pointer     | p        |

### Pointer notation
| Pointer type       | Notation |
| ------------------ | -------- |
| Pointer            | _        |
| Pointer of Pointer | __       |

### Char-Array/String notation
char cTest[\<String-Length\> + 1] = "";
OR
char cTest[] = "Hi. Ich bin ein Example!";

### Examples
#### Integer
int iTest = 0:

#### Unsigned Integer
unsigned int uiTest = 0;

#### Float
float fTest = 0.0;

#### Unsigned Float
unsigned float ufTest= 0.0;

#### String
char cTest[10 + 1] = "";

#### Integer-Pointer
int \*i_test = NULL;

#### Unsigned Integer-Pointer
unsigned int \*ui_Test = NULL;

#### Pointer
\<DATA-TYPE> \*p_\<VARIABLE-NAME> = NULL;

TEST \*p_test = NULL;
